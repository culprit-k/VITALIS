# Exact-source cross-cohort patient-cluster bootstrap: 1,000 replicates

Date: 14 October 2026

## Scope and method

- Set B contains 20,000 patients, 761,995 hourly rows, and 10,780 positive hourly labels.
- Model split seeds: 42, 123, and 2026. For each seed, 1,000 paired patient-cluster bootstrap replicates were computed for both raw and Platt-recalibrated probabilities. Bootstrap seed = model split seed + 90,000.
- Raw Set-B scores were generated by the checked-in `scripts/evaluate_cross_cohort.py` (Git blob `dc736ef7a7fe31c477d4626971dd5b0abd255d2f`). Recalibrated scores were generated by the checked-in `scripts/evaluate_cross_cohort_recalibration.py` (Git blob `fe355c4b7b77b322ae5c134fe7fdc0b9cbb73200`), with Platt recalibrators fitted only on disjoint Set-A validation patients. Set B was never used for fitting, recalibration, feature selection, or threshold selection.
- The accelerated, tie-aware bootstrap implementation is checked in at `scripts/bootstrap_heldout_scores_fast.py` (Git blob `92b41af5f96f251ce39a222d026c23fd9102a15b`) and uses the optional `bootstrap-accelerated` dependency extra for Numba.
- Validation: 25 synthetic tied-score fixtures matched scikit-learn weighted AUROC, average precision, and Brier metrics within 1e-12. For all six seed/stream combinations, the first 200 replicates matched the stored checked-in-runner means and 95% interval endpoints within 4e-14 absolute difference. The new runner's focused tests passed locally (7 passed). GitHub Actions passed on code-bearing commit `da7d33a43c363f24c48f77eb6ca79576175fdce9` (run https://github.com/culprit-k/VITALIS/actions/runs/38606538416); the later `e68faf6f4ccf1e777260ced71c276039daf16137` commit updates the roadmap documentation only.
- Score archives and chunk-level bootstrap differences remain outside Git. Only aggregate results are committed in [the JSON artifact](../results/cross_cohort_paired_patient_cluster_bootstrap_raw_and_recalibrated_exact_source_1000x3_2026-10-14.json).

## Interpretation and limits

- In all three split-specific runs, temporal features had higher AUROC and AUPRC than static features; all intervals for those differences were above zero. The temporal-minus-static Brier difference was below zero in every raw and recalibrated run.
- Platt recalibration is monotonic, so it preserves ranking to numerical precision. Its Brier-score contrasts are much smaller than raw-score contrasts.
- These are conditional intervals for the fixed held-out Set-B cohort and each Set-A split. Three split-specific intervals are not a pooled confidence interval, independent external validation, or evidence of prospective clinical performance.
- The labels are retrospective hourly challenge labels, not adjudicated event-level outcomes. These results do not establish clinical calibration, decision utility, patient benefit, or a clinically valid threshold. VITALIS remains research-only.

## Reproduction

Install the optional acceleration dependency with `python -m pip install -e ".[bootstrap-accelerated]"`. Generate score archives with the checked-in raw evaluator or recalibration runner using `--local-score-archive-dir` pointing outside the repository, then run:

```bash
python scripts/bootstrap_heldout_scores_fast.py \
  --scores /path/outside/repository/heldout_scores_seed_42.npz \
  --replicates 1000 --batch-size 8 --seed 42 \
  --output results/bootstrap_seed42_aggregate.json
```

Use the matching local archive and model seed for each stream. Never commit NPZ score archives, patient group vectors, or row-level bootstrap differences.
